# Lesson 11 – Http Datenübertragen

## Daten mit Requests senden

Oft werden mit einem Request auch Daten an einen Server gesendet.<br/>
Sie habe zuvor bei den Request bereits kennengelernt, die Stichworte für eine Suche bei Google mitgibt.<br/>
ZBsp. der Suchbegriff "HTML Formulare".<br/>
```text
https://www.google.ch/search?q=HTML+Formulare
```
Aus Formularen können aber auch komplexere Daten an einen Server gesendet werden.<br/>
ZBsp _Name und Adresse_ an den fiktiven Server _meinServer.bbw.ch_ <br/>

```text
Paul Muster
Pionierstrasse 28
8404 Winterthur
```

```text
#Get Request mit URL-Parametern
https://meinServer.bbw.ch/personen?name=Paul+Muster&street=Pionierstrasse+28&plz=8404&city=Winterthur
```
Beim Post Request werden die Daten im **Body** des Requests gesendet.<br/>
Beispiel:
```text
#Post Request mit Body
POST https://meinServer.bbw.ch/personen
Content-Type: application/x-www-form-urlencoded
name=Paul+Muster&street=Pionierstrasse+28&plz=8404&city=Winterthur
```

Oder heute häufiger beim Post Request im JSON Format:<br/>
Beispiel:
```text
#Post Request mit JSON
POST https://meinServer.bbw.ch/personen
Content-Type: application/json
{
  "name": "Paul Muster",
  "street": "Pionierstrasse 28",
  "plz": 8404,
  "city": Winterthur"
}
```

### Übertragene Daten sichtbar machen und analysieren

Nun werden Sie **Daten an einen Server schicken** und die **übertragen Daten sichtbar machen** und analysieren.<br/>
Den Request lösen Sie hier in der Lesson aus.<br/>, sichtbar machenIn dieser Lession werden Sie die Daten, die an einer Server geschickt werden sichtbar machen.<br/>
Und als Server verwenden wir einen **Web-hook Dienst**.

Was ist ein Web-hook Dienst?<br/>
Ein Web-hook Dienst ist ein Online-Dienst, der es ermöglicht, **HTTP-Anfragen (Requests) zu empfangen und deren Inhalt anzuzeigen**.<br/>
Er wird für Testzwecke verwendet, um zu überprüfen, welche Daten von einem Client an einen Server gesendet werden.<br/>
Der Vorteil ist, dass der **Client-Server-Kommunikation simuliert** werden kann, ohne einen eigenen Server einrichten zu müssen.

Des Ergebnis zeigt er Webhook auf seiner Webseite an.
